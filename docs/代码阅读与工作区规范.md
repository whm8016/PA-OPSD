# 代码阅读与工作区规范

更新时间：2026-11-21。研究依据是根目录的 `开题报告_OPSD自进化_v3.docx`。

## 先看当前做到了什么

1. **LongTutor 基模型复现。** Qwen2.5-7B-Instruct 已对 Gold 1,000 条生成预测，Gemini 完整评分 676 条，其中官方发布顺序的前 500 条已评完。前 500 条的指标接近论文表 2。论文未公开逐题预测，逐题一致性尚无法核验。
2. **Gold 训练试验。** 已固定 560 训练、140 验证、300 测试的划分，并跑过 SFT、等步数 SFT 续训和 token 级 OPSD。早期试验使用自己的简化计分，与 LongTutor 官方表格的计分口径不同。
3. **开题方案进度。** 当前蒸馏只覆盖 token 级。八类教学动作的显式预测与动作级损失，以及技能快慢循环，仍需实现和验证。

## 找数据和结果

- LongTutor 官方仓库位于 `data/longtutor/repo/`。复现时使用的干净上游代码快照位于 `outputs/longtutor_b1/official_ba40af3/upstream/`。
- 复现结果位于 `outputs/longtutor_b1/official_ba40af3/autodl_5090_20765/`。`preds.jsonl` 是 1,000 条模型输出，`metrics.jsonl` 是 676 条已完成评分，`reproduction_results.json` 是对照汇总。
- 固定划分与训练试验位于 `outputs/pa_opsd/gold_split_20261120/`。`split_manifest.json` 记录样本划分，`development/` 和 `sealed/` 分别保存开发部分与封存部分。模型、日志和结果均在该实验目录中。
- `archive/工作区导航_历史副本/` 是先前制作的分类副本，可能落后于源码。实际阅读和修改以上表的原路径为准。

## 其他目录如何理解

`scripts/build_pa_opsd_seed.py`、`generate_pa_opsd_teacher.py`、`build_pa_opsd_pilot.py` 等属于先前合成数据与试验流程，现阶段可以暂缓阅读。`external/`、`ScaffoldLM/` 和根目录原始 OPSD 相关文件包含参考项目及共享依赖，是否有用应按调用关系核实。接口评测材料归档于 `archive/relay_20261121/`，历史试验结果归档于 `outputs/pa_opsd/archive_pre_gold_20261120/`。`archive/整理清单_20261121.json` 记录原路径和新路径。归档内容保留原样，其中硬编码旧路径的历史脚本运行前需要调整。`papers/`、`doc/`、`docs/` 保存文献及方案。

## 今后怎么放

协作时遵循根目录 `AGENTS.md`。新增功能代码按功能集中到 `scripts/`，独立实验放 `scripts/experiments/<实验名>/`，配一份简短 README 说明用途、数据流、运行及验证方式。数据放 `data/`，输出放 `outputs/<项目>/<实验名>/`，临时材料放 `.codex_tmp/`，文档放 `docs/`，测试放 `tests/`。更新现有入口时保持调用路径有效，并同步本阅读指南。
