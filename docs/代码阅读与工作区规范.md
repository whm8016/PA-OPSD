## 其他目录如何理解

`scripts/build_pa_opsd_seed.py`、`generate_pa_opsd_teacher.py`、`build_pa_opsd_pilot.py` 等属于先前合成数据与试验流程，现阶段可以暂缓阅读。`external/`、`ScaffoldLM/` 和根目录原始 OPSD 相关文件包含参考项目及共享依赖，是否有用应按调用关系核实。接口评测材料归档于 `archive/relay_20261121/`，历史试验结果归档于 `outputs/pa_opsd/archive_pre_gold_20261120/`。`archive/整理清单_20261121.json` 记录原路径和新路径。归档内容保留原样，其中硬编码旧路径的历史脚本运行前需要调整。`papers/`、`doc/`、`docs/` 保存文献及方案。

## 今后怎么放

协作时遵循根目录 `AGENTS.md`。新增功能代码按功能集中到 `scripts/`，独立实验放 `scripts/experiments/<实验名>/`，配一份简短 README 说明用途、数据流、运行及验证方式。数据放 `data/`，输出放 `outputs/<项目>/<实验名>/`，临时材料放 `.codex_tmp/`，文档放 `docs/`，测试放 `tests/`。更新现有入口时保持调用路径有效，并同步本阅读指南。
